## FreeWheel v2.1.0

> [!WARNING]
> **USE AT YOUR OWN RISK.** FreeWheel/VeloLauncher is an unofficial community project, not affiliated with or endorsed by Bowflex/Nautilus/JRNY. The maintainer no longer owns a Velocore bike, so this release (installer v2.1.0, embedding VeloLauncher/SerialBridge v1.5.0) has **NOT been tested on real hardware**. Modifying your bike may void your warranty and could leave it in a state requiring a factory reset. Provided AS IS, without warranty of any kind (see [LICENSE](https://github.com/ril3y/freewheel/blob/main/LICENSE)).

The installer now asks you to accept this before it jailbreaks. Restore Stock is not gated.

### Fixes
- **WiFi/Bluetooth no longer broken by the installer.** v2.0.1 was built before the fix that stopped disabling Google Play Services / Google Services Framework; this is the first release that includes it. **Restore Stock also stopped disabling them** (it was still doing it), and now re-enables them, so WiFi and ADB-over-WiFi keep working after a restore.
- **Release launcher, not a debug build.** v2.0.1 embedded a debug VeloLauncher. This release embeds the release APKs from [velo-platform v1.5.0](https://github.com/ril3y/velo-platform/releases/tag/v1.5.0), built by GitHub Actions. A `SHA256SUMS` file is attached.
- **Stock apps can no longer fight SerialBridge for the serial port.** The jailbreak now checks that NautilusLauncher and JRNY are disabled and not running before SerialBridge starts (and again after), and stops them if they are. Two apps reading the port at once corrupts the sensor data.
- **Overlay permission is verified.** The floating home button / ride-stats overlay needs `SYSTEM_ALERT_WINDOW`. The jailbreak now checks it was granted and prints the manual fix if not.
- **Sensor check at the end of the jailbreak.** The last step reads SerialBridge's new status line and tells you in plain words whether the bike's sensors are talking.
- Step numbering in the jailbreak (1-9, no gap) and restore (1-7) log fixed. Steps that could not reconnect now warn instead of being skipped silently.

### One-time launcher reinstall
VeloLauncher's signing key changed (debug key to release key), so the launcher's built-in updater cannot upgrade an existing install. Run **Jailbreak** again from this version of FreeWheel; on an already-jailbroken bike it runs as an update and reinstalls both apps. Reinstalling removes VeloLauncher's app data on the bike, including local ride history.

### Reporting problems
There is no bike to test on, so reports with logs are what will get things fixed. Please [open an issue](https://github.com/ril3y/freewheel/issues) and include:
1. The FreeWheel output (use the copy button at the top-right of the log).
2. The sensor status line from **Settings > Diagnostics** in VeloLauncher (status and FW lines).
3. Bridge logs, captured from a PC on the same WiFi with [ADB platform-tools](https://developer.android.com/tools/releases/platform-tools), ideally while pedaling in a ride:
   ```
   adb connect <bike-ip>:5555
   adb logcat -d -s SerialBridge:* > bridge.txt
   adb shell ps -A | grep -i nautilus
   ```

See [Troubleshooting](https://github.com/ril3y/freewheel#troubleshooting) for common issues (sensors at zero, other people's accounts in apps, bike turning back on, missing overlay).
